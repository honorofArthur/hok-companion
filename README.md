# Honor of Kings Companion

A clean English companion website for the Chinese version of Honor of Kings focused on items, stats, filtering, sorting, comparison tools, and future build-planning systems.

---
# Project Vision

This project aims to create a modern, readable, English-friendly database and companion tool for the Chinese version of Honor of Kings.

The goal is to provide:

* Clear item information
* Faster browsing and filtering
* Better stat visibility
* Easier comparison tools
* Future build planning systems
* English accessibility for non-Chinese players

# Design Philosophy

The UI focuses on:

* Low clutter
* Fast readability
* Strong information hierarchy
* Minimal unnecessary effects
* Compact but readable layouts

The goal is to feel modern and premium without becoming visually exhausting.
