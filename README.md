# Honor Of Kings Companion

An English-translated item database for the Chinese version of Honor of Kings.

## Features

- Category navigation
- Dual-stat sorting
- Compact item cards with stat tags
- Expanded detailed item view
- Side-by-side item comparison
- Mobile-friendly inspector panel

## Goal

Create a modern English resource for the Chinese version of Honor of Kings, focused on clarity, accessibility, and fast item browsing.
