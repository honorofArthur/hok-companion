# Honor of Kings Companion

English companion website for the Chinese version of Honor of Kings.

## Features
- Browse Honor of Kings CN items
- Filter by category
- Sort by core stats
- Detailed item inspector panel

## Status
Early development. Item data is still being expanded and refined.

## Files
- `index.html` - page structure
- `style.css` - visual styling
- `script.js` - item data, rendering, filters, sorting, comparison
- `items.js` - item database
- `images/` - item icons
